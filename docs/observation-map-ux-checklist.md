# 관찰 지도 UX 육안검증 체크리스트 (실기기)

> 브레인이 오너에게 제시한 검증 리스트 원문(수정 없이 보존) + 오너 피드백(2026-09-13).
> 시뮬 위치권한 다이얼로그를 브레인이 탭할 수 없어(idb/cliclick 없음) 오너 실기기 육안검증으로 진행.

---

## 1. 브레인이 제시한 체크리스트 (원문, 수정 없음)

### A. 진입 & 기본 지도
1. **다크 타일 렌더** — 지도가 어두운 회색(Esri Dark Gray)으로 뜨는지, "API KEY REQUIRED" 워터마크 **없는지**
2. **핀 3종 구분** — 조류=청록 물방울, 별=앰버, 노포=회갈색 사각(색+모양 둘 다 다른지)
3. **온-맵 라벨** — 핀 옆에 이름/측정값("여차리 갯벌 · 저어새 12", "SQM 21.7")이 **기본 화면에서 보이는지** (이게 "너무 달라" 고친 부분)
4. **낮/밤 정합** — 홈에서 낮/밤 토글 후 지도 오면, 낮엔 지도가 살짝 밝게 물드는지

### B. 레이어 칩 (상단)
5. 칩 **가로 스크롤**로 5종(전체/조류/별/노포/트레일) 다 닿는지, 잘림/오버플로우 **없는지**
6. 칩 끄기/켜기 → 해당 핀만 사라지고 나타나는지, 전부 끄면 "레이어 선택" 안내
7. **트레일 칩 켜기** → 지도에 GPX 경로 선이 그려지는지

### C. ⭐ 조류 산포 리빌 (017 — 이번 핵심)
8. **조류 핀/리스트 탭** → 그 지점으로 **확대(줌인)**되는지
9. 확대되며 **새 마커들이 좌표 주변에 흩뿌려지며 등장**하는지 (한 번에 팍 말고, 순차로 퍼지는 stagger 느낌)
10. 산포된 새 개수가 그 스팟 개체수와 맞는지 (Phoenix Lake=6마리 정도)
11. **대량 스팟**(알락꼬리마도요 280 등) → 새는 ~25마리로 제한 + **"관측 N마리 · 대표 표시"** 캡션 뜨는지 (거짓 아님을 알리는 정직 표기)
12. 산포 중 **주변 다른 핀 라벨이 억제**되어 화면이 안 지저분한지
13. **개체 새 탭** → 종명 툴팁 뜨는지
14. **줌아웃 / 다른 스팟 탭 / 시트 올리기** → 산포가 걷히고 원래 관측지 핀으로 복귀하는지

### D. 바텀시트
15. **3-스냅 드래그** — peek(작게)↔중간↔전체, 걸리는 느낌 자연스러운지
16. peek에서 "관찰 스팟 N곳" 카운트, 오버플로우 **없는지**
17. **검색바**에 스팟명 입력 → 지도·리스트 동시 필터
18. **정렬칩**(거리/최근관측/SQM) + SQM 필터 동작
19. 스팟 탭 → 상세: **측정값(종·SQM·주소) 위 / 구분선 / 적합도 게이지 아래** 로 분리, 리스트엔 적합도 점수 **없는지**

### E. 오버레이 & 기타
20. 좌하단 **조석/음력 오버레이**("간조 22:52 · 월령 28.8일") — 지도·시트에 안 가리는지
21. 지도 **회전** → 우측 **나침반(N)** 등장, 탭하면 북향 리셋 (정북이면 숨김)
22. 조류 상세에 **"커뮤니티 관측" 배지 + "N일 전"**, "실시간" 문구 **없는지** (eBird 정직 표기)

### F. 실데이터 & 엣지
23. **백엔드 연결** — 스팟이 실제로 뜨는지 (안 뜨면 Wi-Fi/방화벽 문제)
24. 긴 이름(영문 종명 등)에서 **텍스트 잘림/오버플로우 없는지**
25. 위치 거부 시 → 강화 기준 폴백 + 안내 배너 + 크래시 없는지

## 2. 오너 피드백 (2026-09-13, 실기기 1차 검증)

### 개선 요청 (액션 필요)

- **[1] 최대/최소 줌 한정** — 너무 확대하면 "Map data not yet available". 확대/축소 배율 상한·하한을 두고 싶음. **한국 지도만** 필요(전 세계 불필요). → 요청: 한 번의 빌드로 배율을 시험할 수 있게 **임시 버튼 등** 넣어서 min/max zoom을 정할 수 있게.
- **[2] 핀 3종** — "다 다르게 보여" (✅ OK로 해석).
- **[3] 온-맵 라벨이 너무 길어 항상 생략됨** — 지금 **주소 원문**이 표시됨(예 "632-15 역북동, 용인시, 경기도, KR(...)"). 원하는 수준 = **"여차리 갯벌"** 같은 간결한 장소명. 라벨 축약/장소명 소스 개선 필요.
- **[3b] 새 핀(개체 마커) 백그라운드 없어 누르기 힘듦** — 히트 영역/배경 개선. 그리고 **개체 마커 탭 → 바텀시트에 새 정보 + 노출 위치**가 나오면 좋겠음(툴팁 대신 시트 상세).
- **[B] "이곳에서 다시 검색" 버튼** — 위치 이동 시 현재 지도 중심으로 재검색하는 버튼 필요. (질문: 지금은 최초 설정 지역 정보만 보이는 거 맞는지?) → 이거 개선되면 B영역(5~7) 재확인 예정.
- **[C-8] 확대가 과함** — 확대는 되는데 너무 많이 확대돼 오류처럼 보임([1]과 연결 — 줌 상한).
- **[C-10] 산포 개수 = 종 수** — 현재 개체수(count 합) 기준인데, **종(species) 수만큼**으로 변경 원함(예: 조류 4종 관측 → 새 마커 4개).
- **[C-13] 종 상세 + 마커에 종명 표시** — 툴팁이 잠깐 뜨고 사라져 못 봄. 원하는 것: (a) 개체 마커에 **종명이 항상 표시**(누르기 전에 어떤 새인지 알 수 있게, 예 '황조롱이'), (b) 개체 탭 → **종 상세**(발견 위치·종 사진·종 특징 등).
- **[D-15] 시트 핸들(grabber)을 잡고 드래그하면 아무 동작 안 함** — (질문: 플러터에서 핸들 드래그가 원래 안 되는 동작인지?) 시트 본문 드래그는 됨.
- **[D-17] 검색바가 안 보임** — "검색바 없는데." (검색바 미노출 = 버그/발견).
- **[E-21] 확대/축소 시 지도가 회전됨** — 불편. 확대/축소(핀치) 중엔 **회전 잠금** 원함.

### 확인 완료 (OK)

- **[D-16]** 오버플로우 없음 ✅
- **[F-23]** 스팟 실제로 뜸(백엔드 연결 OK) ✅

- **[D-16] "관찰 스팟 N곳"이 무슨 기준**으로 뜨는지.
