## 동작하는 기능

- 전체·산림/습지·도서/갯벌 필터와 해당 유형의 빈 목록 안내
- 패키지별 일정·가격·혜택·장비 안내
- 예약 미리보기에서 희망 출발일·인원(1~6명) 선택 및 예시 총액 계산
- 선택 내용을 보여주는 로컬 미리보기. 실제 예약 접수·데이터 저장·서버 전송은 없음
- 고정 하단 이용 안내, 낮·밤 테마 및 큰 글씨 대응

날짜 선택기에서 선택 가능한 날짜는 예약 가능한 출발일을 의미하지 않는다. 이번 작업에서 실제 상담·예약·결제 및 운영사 연결은 구현하지 않았다.

## 구현 파일

- `apps/flutter/lib/models/stay_package.dart`: 예시 모델·일정·가격
- `apps/flutter/lib/screens/packages_catalog_screen.dart`: 네 번째 탭과 필터
- `apps/flutter/lib/screens/package_booking_preview_screen.dart`: 로컬 예약 미리보기
