# 〈위를 봐요〉 디자인 레퍼런스

두 스타일 레퍼런스를 **함께** 쓴다. 어느 하나도 철회하지 않는다. 레퍼런스의 문구·로고·이미지(arte*, Flim 워드마크, 사진)는 복제하지 않고 〈위를 봐요〉 브랜드 콘텐츠로 재구성한다.

| 파일 | 레퍼런스 | 원본 |
|---|---|---|
| [arte.md](arte.md) | arte* — Golden hour harvest editorial | https://styles.refero.design/style/2f94c1f0-cd23-4bf1-95f3-0e531174c4f4 |
| [flim.md](flim.md) | Flim — Scattered polaroids on a sketchpad grid | (원본 URL 미전달) |

두 파일은 받은 원문을 그대로 저장했다. 아래 내용은 〈위를 봐요〉에 적용하기 위한 해석이며, 원문과 다를 때는 이 문서가 우선한다.

## 1. 역할

| 영역 | 주 기준 | 함께 쓰는 기준 | 관련 spec |
|---|---|---|---|
| Flutter 앱(웹·Android) 낮·밤 테마, 공통 UI | **Flim**: 흑백 대비, 간결한 버튼·카드, 큰 제목, 넓은 여백, 그림자 없음 | — | 053, 054, 055, 058 |
| 브랜드 홈페이지 히어로 | **확정 브랜드 비주얼**: 검정 배경 + 날개 편 새 실루엣 + 확정 메인 카피 | — | 059 |
| 브랜드 홈페이지 히어로 이후 섹션 | **arte\***: 크림·짙은 녹색·노란색 배경과 전환, 문장 배치·정렬·겹침, 대형 타이포, 사진과 글자의 결합 | **Flim**: 강한 흑백 타이포 블록 | 059 |
| 로고·앱 아이콘·웹 로딩 화면 | 확정 브랜드 비주얼 | Flim 흑백 바탕 | 056 |

## 2. 충돌 시 우선순위

1. **사용자가 확정한 내용**(브랜드 메인 카피 원문, 검정 배경 새 실루엣, 앱 낮·밤 흑백 색상)이 최우선이다.
2. **접근성**(명도 대비 WCAG 2.1 AA: 일반 글자 4.5:1, 큰 글자·비텍스트 3:1)이 레퍼런스의 색 조합보다 우선한다. 레퍼런스 팔레트는 지우지 않고 **글자·바탕 조합만 제한**한다.
3. **한글 사용성**이 레퍼런스 타이포 수치보다 우선한다(한글 제목 줄간격 1.1 이상, 한글에는 대문자·넓은 자간 규칙을 적용하지 않음).
4. 영역별 주 기준(1절)이 다른 레퍼런스보다 우선한다. 예: 모서리는 앱 = Flim(버튼 8 · 카드 16 · pill 원형 · 링크 4), 홈페이지 = arte*(버튼 31 · 카드 20 · 태그 원형 · 기타 64).

## 3. 앱 색상 (사용자 확정 + Flim)

| 역할 | 낮 | 밤 |
|---|---|---|
| 바탕 | `#FFFFFF` | `#141414` |
| 본문 | `#141414` | `#FFFFFF` |
| 보조 글자 | 053에서 대비 검사로 확정 | 흰색 약 70%를 기본 후보로, `#141414` 위 대비 검사 후 조정 |
| 주요 버튼 | `#141414` 채움 + 흰 글자 | `#FFFFFF` 채움 + `#141414` 글자(배경과 반전) |
| 보조 면·경계선 | Flim Mist `#e9e9e9`, Hairline `#d9d9d9` | 같은 역할의 어두운 값(053에서 확정) |
| 상태·출처 보조색 | Flim Signal Green `#30a81d`, Forest `#21935b`, Ember `#ff8400`, Highlight Yellow `#fecc33`를 **점·작은 테두리**에만 제한 사용 | 같음 |

- `#141414`/`#FFFFFF` 대비는 약 18:1로 두 모드 모두 통과한다.
- 흰 바탕에서 Forest(약 3.9:1)·Signal Green(약 3.1:1)은 글자 기준(4.5:1)에 못 미치므로 점·아이콘에만 쓴다. Ember·Yellow는 흰 바탕에서 3:1에도 못 미치므로 낮 모드에서는 진한 변형을 053에서 정하거나 밤 모드에서만 쓴다.
- 출처 칩(`실시간`/`추정`/`예시`/`지연`)의 글자는 항상 본문색(흑/백)으로 쓰고, 색은 점·모양에만 쓴다(색만으로 구분하지 않음).

## 4. 홈페이지 색상 (arte* 유지 + 대비 제한)

arte* 팔레트(Wheat Cream `#e5dccd`, Harvest Copper `#ab5700`, Citron Beam `#e8e359`, Morning Glory `#7997ff`, Amber Glow `#d99623`, Forest Floor `#214534`, Deep Moss `#103d26`, Olive Branch `#568037`, Slate Bloom `#3d549c`, Coral Petal `#e99686`)는 그대로 쓴다. 글자·바탕 조합은 아래처럼 제한한다(근사 계산값, 059 구현 때 재검사).

| 조합 | 대비 | 사용 |
|---|---|---|
| Forest Floor 글자 / Wheat Cream | 약 5.4:1 | 본문 가능 |
| Harvest Copper 글자 / Wheat Cream | 약 2.5:1 | 장식선·큰 장식 글자만, 본문 불가 |
| Morning Glory 글자 / Wheat Cream | 약 1.4:1 | 크림 위 글자 불가(짙은 바탕에서만) |
| Slate Bloom 글자 / Wheat Cream | 약 3.6:1 | 큰 글자만 |
| Citron Beam 글자 / Wheat Cream | 약 1.5:1 | 크림 위 글자 불가 |
| Citron Beam 글자 / Deep Moss | 약 9:1 | 가능 |
| Citron Beam 글자 / 검정 | 약 15:1 | 가능 |

## 5. 폰트

| 용도 | 레퍼런스 | 앱 | 홈페이지 |
|---|---|---|---|
| 본문·기본 한글 | Arial(Flim), Poppins(arte*) | **Pretendard**(앱에 번들, 기본 폰트) | Pretendard |
| 큰 제목 | Swizzy 500 · −0.02em · 0.86(Flim), Parafina 500 · 0.8~0.9(arte*) | Pretendard 굵기 500~600, 자간 −0.02em, 한글 줄간격 1.1 이상 | 같은 원리. 라틴 표시용 추가 폰트는 **보류**(사용자 결정) |
| 라벨·숫자 | PP Neue Montreal Mono · 대문자 · 0.06em(Flim) | 역할 정리 후 결정(아래 현황) | 보류 |

현재 앱의 폰트 사용 현황(2026-10-29 조사, 제거는 현재 단계에서 하지 않음):

| 폰트 | 들어오는 곳 | 실제 사용 |
|---|---|---|
| Space Grotesk | `lib/theme/app_theme.dart`의 display·headline 역할, `lib/screens/login_screen.dart` 버튼 3곳 | display 역할 사용 0건, headlineMedium 1건, headlineSmall 9건(대부분 한글 제목 → 한글은 시스템 대체 글꼴로 그려짐), 로그인 버튼 라벨 |
| Inter | 기본 본문 텍스트 테마 | title·body 역할 전반(titleSmall 15, bodyMedium 16, bodySmall 37 등). 한글은 대체 글꼴 |
| JetBrains Mono | labelSmall·labelMedium 역할 | labelSmall 45건, labelMedium 6건. 상당수가 한글 라벨(예: "추정치", 거리 표시) → Flim 원칙(모노는 영문·숫자 라벨만)과 다름 |

세 폰트 모두 `google_fonts`로 실행 중 내려받으므로 오프라인 Android에서는 적용되지 않는다. 역할 정리안은 spec 053에 둔다.

## 6. 공통 원칙

- 그림자 없음. 깊이는 경계선 1px, 면 색 차이, 여백으로 만든다(두 레퍼런스 공통).
- 앱 본문은 왼쪽 정렬(Flim). 로그인처럼 브랜드 장면은 예외로 가운데 정렬을 허용한다.
- 적합도는 '참고 지표', eBird는 '시민과학 데이터', 실제 기능이 없는 미션은 '시범', 실제 상품이 아닌 패키지는 '예시'로 표시한다. 종 출현·관측 결과를 단정하지 않는다(spec 058).
